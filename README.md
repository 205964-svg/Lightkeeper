1. Visão geral
Lightkeeper é um jogo do gênero Tower Defense desenvolvido na Unity 2D.
O jogador deve proteger um farol contra criaturas sombrias utilizando torres defensivas e a luz como principal mecânica de combate.

2. Objetivo
Sobreviver ao maior número possível de ondas de inimigos, impedindo que destruam o farol.

3. Mecânicas principais:

-> Luz e sombra: a luz revela, causa dano e desacelera os inimigos. Obstáculos bloqueiam os feixes e criam áreas de sombra.
-> Torres defensivas: podem ser construídas pelo jogador para detectar e atacar criaturas.
-> Inimigos: avançam em direção ao farol e se movimentam mais rapidamente quando estão no escuro.
-> Construção: permite posicionar torres em locais válidos do mapa.
-> Recursos: obtidos principalmente ao eliminar inimigos e utilizados para construir novas torres.
-> Ondas: a dificuldade aumenta progressivamente com o surgimento de mais inimigos e o fortalecimento das criaturas.

4. Direção visual
O jogo terá perspectiva 2D lateral e estilo visual estilizado.
O cenário será predominantemente escuro, com luzes em tons quentes para destacar o farol, as torres e os feixes luminosos.

5. Tecnologias:

-> Unity 2D
-> C#
-> Unity UI
-> Prefabs e ScriptableObjects

6. Escopo do protótipo
A primeira versão deverá incluir:

-> Cenário com o farol e obstáculos.
-> Sistema de vida da base.
-> Geração e movimentação de inimigos.
-> Torres com direcionamento automático.
-> Sistema de luz, dano e lentidão.
-> Construção de torres e gerenciamento de recursos.
-> Ondas progressivas.
-> Interface básica.
-> Condição de derrota.

7. Funcionalidades futuras:

-> Novos tipos de torres e inimigos.
-> Melhorias para as estruturas.
-> Chefes e inimigos especiais.
-> Novos mapas.
-> Sistema de pontuação e recordes.
-> Melhorias visuais e sonoras.

8. Condição de derrota
A partida termina quando a vida do farol chega a zero.

9. Objetivo do desenvolvimento
O foco inicial é criar um protótipo funcional que valide as mecânicas de luz e sombra, a construção de torres e a progressão das ondas antes da expansão do conteúdo.
