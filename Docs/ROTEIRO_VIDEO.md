# Lightkeeper — Roteiro do vídeo de demonstração (≈ 3 min)

> Critério "Demo em vídeo" (0,5 pt). O link do vídeo precisa estar no README.

## Como gravar (Windows, sem instalar nada)

1. Descompacte `Executavel/Lightkeeper-Windows.zip` e abra `Lighkeeper.exe`.
2. Com o jogo em foco, aperte **Win + Alt + R** para começar a gravar (Xbox Game Bar).
   Aperte de novo para parar. O vídeo vai para **Vídeos > Capturas**.
   - Para gravar com voz: **Win + Alt + M** liga o microfone (ou grave a narração depois).
   - Alternativa: **OBS Studio** (grátis) com "Captura de janela".
3. Suba no **YouTube como "Não listado"** (ou Google Drive com link público) e cole o link no README.

## Roteiro

| Tempo | Tela | O que fazer | Narração sugerida |
|---|---|---|---|
| 0:00–0:15 | Menu | Mostrar o título; digitar o nome | "Lightkeeper é um Tower Defense 2D feito em Unity. Proteja o farol das criaturas da sombra." |
| 0:15–0:30 | Como Jogar → Voltar | Abrir o painel de regras | "Construímos torres de luz em pedestais. Fora da luz, as criaturas ficam mais rápidas." |
| 0:30–0:40 | Menu | Clicar **Jogar – Fácil** | "Temos três dificuldades: Fácil, Médio e Difícil." |
| 0:40–1:20 | Jogo | Construir 2 **Lanternas** perto da caveira; passar o mouse para mostrar o **alcance** | "A Lanterna dispara faíscas rápidas no inimigo mais adiantado. Cada abate rende luz para construir mais." |
| 1:20–1:50 | Jogo | Quando tiver 90 de luz: tecla **2** e construir um **Prisma** perto de um Colosso | "O Prisma é lento, mas causa dano em área e deixa os inimigos lentos — repare no tom azulado." |
| 1:50–2:05 | Jogo | Clique direito numa torre (vender); **P** para pausar e despausar | "Dá para vender torres por metade do preço e pausar a qualquer momento." |
| 2:05–2:20 | Jogo | Deixar um inimigo chegar ao farol | "Se uma criatura alcança o farol, ele perde vida e treme." |
| 2:20–2:35 | Fim | Tela de **vitória** | "Vencemos ao resistir a todas as ondas com o mínimo de abates." |
| 2:35–2:45 | Menu → Ranking | Mostrar o ranking com a pontuação | "A pontuação vai para o ranking." |
| 2:45–3:00 | Menu → **Difícil** | Jogar ~10 s até aparecer a **Hidra** (onda 2) | "No Médio e no Difícil surge a Hidra, de duas cabeças: mais rápida e resistente." |

**Dicas:** grave em tela cheia ou janela grande; feche notificações (WhatsApp/Discord) antes;
se errar, não precisa refazer tudo — corte no editor de vídeo do Windows (**Clipchamp**, já instalado).
